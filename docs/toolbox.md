# 工具箱与按掩膜提取

点击顶部红色工具箱图标，或选择“地理处理 → 工具箱”，打开独立工具箱窗口。

工具箱支持按名称、简介、英文关键词搜索；多个词以空格分开时同时匹配。
左侧分类与搜索条件共同生效。每张工具卡显示名称、简介、分类和“打开”按钮。

- 叠加分析：裁剪、相交、联合、缓冲区。
- 数据管理：合并、融合。
- 栅格提取：按掩膜提取。

已有矢量工具继续使用原有参数窗口与处理流程。

## 按掩膜提取

1. 将输入栅格和掩膜图层加入地图；隐藏或位于折叠分组中的图层同样可选。
2. 打开“按掩膜提取”，选择输入栅格与面 / 栅格掩膜。
3. 选择一个不存在的 `.tif` 或 `.tiff` 输出路径，然后点击“运行”。
4. 可查看进度并取消；关闭参数窗口不会停止后台处理。完成后输出自动加入地图。

### 运算规则

- 使用现有 Rust `geo` 和 `tiff` 库，无 GDAL 运行时依赖。
- 面掩膜以像元中心是否落在面内或边界上判定，支持多个面与孔洞。
- 栅格掩膜使用第一个波段：有限、非 NoData 的值均有效，包括零。
  不同分辨率的掩膜按输入像元中心最近邻采样，不改变输入网格。
- 保留所有输入波段、像元大小、网格对齐与仿射旋转；输出范围裁至掩膜包围盒
  与输入的交集，并向外对齐输入像元边界。非矩形掩膜外围仍为 NoData。
- 面和栅格掩膜会转换到输入栅格坐标系。转换基于项目现有的纯 Rust
  `CrsTransform`，目前覆盖已识别的经纬度、Web Mercator、UTM 和高斯–克吕格
  投影；其它投影无法识别时会报告转换错误，不会把两组坐标误当成同一坐标系。
  输出目前要求可写入 GeoTIFF 标准 GeoKey 的 EPSG 代码。
- 输出为 Float32 BigTIFF（扩展名仍为 `.tif`），掩膜外和输入无效值统一为
  NaN NoData。Float64 与大整数转换为 Float32 可能发生精度舍入。
  输出保留波段数值与顺序，不复制源文件的调色板、波段描述或显示样式。
- 按条带读取和写入，后台执行；不一次性加载整幅影像。极宽单行或过大的掩膜
  读取窗口会明确报错，而不会无界分配内存。
- 先写同目录临时文件，再以不覆盖目标的方式发布；失败或取消会清理临时文件。
  无空间重叠或掩膜内没有任何输入像元中心时不生成结果。
