# RustGIS

> 用纯 Rust 复刻 ArcGIS 的桌面 GIS 平台：**低内存占用 · 高性能 · 跨平台 · 内存安全**

完整产品文档见 [docs/产品文档.md](docs/产品文档.md)。

## 当前版本（v0.2.2）

- **缓冲区分析（v0.2.2 新增）**：「地理处理 → 缓冲区...」打开**独立顶层窗口**
  （egui 多视口 → 真正的系统窗口，可与主窗口并列摆放），参数对标 ArcGIS「缓冲区」
  工具：输入要素 / 输出要素类（GeoJSON）、距离 [值或字段]（米·千米·英尺·英里·码·
  海里·度）、侧类型 FULL / LEFT / RIGHT / OUTSIDE_ONLY、末端类型 ROUND / FLAT /
  SQUARE、融合类型 NONE / ALL / LIST（按字段取值组合融合）；右侧上下文帮助随悬停
  参数切换；确定后在后台线程计算并**自动把结果图层加入地图**（仅当结果超出当前
  视图时才自动缩放）。几何运算全部委托 **`geo` 0.33**（Buffer / BooleanOps /
  Earcut，纯 Rust、无 C 依赖）；属性来自 GeoJSON `properties` 或 Shapefile `.dbf`。
- **地理处理：叠加分析（v0.2.2 新增）**：「地理处理」菜单下另有对标 ArcGIS
  「Overlay」工具箱的 5 个工具，与缓冲区共用同一套独立窗口骨架：
  **裁剪**（用面图层切分输入：面取交集、线被切断、点保留面内）、**相交**（所有输入
  的公共部分，属性按各输入字段并集合并、重名加 `_1`/`_2` 后缀）、
  **联合**（多个面图层的并集切成互不重叠的要素，重叠区按输入顺序先到先得、
  面积不重复计入）、**合并**（纯拼接，不做几何运算）、**融合**（按字段取值分组
  归并，不勾选字段即「融合全部」）。输入列表的**勾选顺序即叠加顺序**（第 1 个是
  主输入，决定字段列表与默认输出名）；结果同样在后台线程计算、写出 GeoJSON
  （按要素带 `properties`）并自动加入地图；每个工具一种强调色。
- **工程文件（.rustgis）**：「文件 → 新建工程 / 打开工程... / 保存 / 另存为...」
  对标 ArcGIS 文件菜单：单文件 JSON（带版本，当前 v4）保存全部图层（含属性表）+
  地图视图；**打开/保存全程后台线程**（文件对话框 → 序列化/解析 + 三角剖分），
  窗口持续响应；有未保存更改时「新建 / 打开 / 退出（菜单或标题栏 X）」先弹
  "保存更改？"三按钮提示（保存 / 不保存 / 取消）；标题栏显示「工程名 — RustGIS
  版本」（未保存为"未命名"）；
- **数据导入**：「图层 → 添加图层」/「数据 → 导入数据」→ 系统文件选择器，
  支持 **GeoJSON**（`.geojson` / `.json`）与 **Shapefile**（`.shp`，DBF 编码自动检测，含 GBK）；
  **导入全程在后台线程执行**（文件对话框 → 解析 → 几何展开 → 三角剖分），
  期间窗口持续响应并显示阶段提示，导入成功自动缩放至全图并在状态栏提示要素数，
  失败弹出错误对话框；
- **地图渲染**：点 / 线 / 多边形（导入时 Earcut 三角剖分，运行时三角网格批绘制）；
  多边形孔参与填充（孔感知剖分）；
- **视图交互**：左键拖动平移、滚轮以光标为中心缩放、双击缩放至全图；
  「视图 → 放大 / 缩小 / 平移 / 缩放至全图」菜单可用；
- **图层管理面板**（左侧）：图例符号 + 图层名（面/线/点不同符号，配色随样式）、
  隐藏图层弱色、拖拽行调整叠放顺序（拖动中显示落点指示、松手生效）、
  右键菜单显示/隐藏 / 删除（红色警示）；
- **整应用白底浅色主题**：窗口 / 面板 / 地图画布 / 对话框全白，1px 发丝线分隔，
  交互态与强调色统一走 ArcGIS 蓝（`#0071BC`）；Windows 下无控制台窗口，启动即显示主窗体；
- **GUI 骨架**（v0.1）：`eframe / egui`（默认 1280×800）、9 个完整菜单、
  未实现功能统一弹出 **"正在开发中"** 对话框、「退出」关闭窗口、
  「关于 RustGIS」显示版本与渲染字体、状态栏（状态 | 光标经纬度 | 版本信息）；
- **多语言（i18n）**：简体中文 / English / 日本語，启动时跟随系统区域设置，
  可在「帮助 → 语言」中切换；
- **CJK 字体自动加载**：启动时按平台加载系统中文字体（微软雅黑 / 苹方 /
  Noto CJK 等），保证中文与日文正常显示。

## 运行

```bash
cargo run --release     # Windows 下也可直接双击 run.bat
```

地图渲染是逐顶点紧循环（每帧把几十万顶点投影到屏幕并写进顶点缓冲），
**请用 release 运行**：dev profile 即使开了 `opt-level = 1`（见 `Cargo.toml`）
在小数据量下够用，但大图层仍会掉帧。

发布构建：

```bash
cargo build --release
```

测试与质量门：

```bash
cargo test --bin rustgis   # 几何（Earcut 剖分/缓冲区/布尔融合/叠加分析）/ 视图变换 /
                           # 导入展开 / 端到端导入导出 / 工程文件往返 / i18n 覆盖 /
                           # 独立窗口对话框（缓冲区 + 叠加工具）
cargo clippy --all-targets   # 零警告为门禁
```

## 代码结构

```
rustgis/
├─ docs/产品文档.md   # 产品文档（定位、架构、性能目标、路线图）
├─ src/
│  ├─ main.rs         # 入口：eframe 窗口
│  ├─ app.rs          # 主应用：布局编排（菜单条 / 图层面板 / 地图视图 / 状态栏 / 对话框）
│  │                  # = src/app/mod.rs（对话框拆到 app/buffer_dialog.rs 与 app/geoprocess_dialog.rs）
│  ├─ menus.rs        # 菜单定义与渲染（key 驱动 i18n）
│  ├─ dialog.rs       # “开发中” / 错误 / “关于” / “保存更改” 对话框
│  ├─ project.rs      # 工程文件（.rustgis）：版本化 JSON 保存/加载（后台线程）
│  ├─ i18n.rs         # 国际化：语言检测 + 三语翻译表（含单元测试）
│  ├─ fonts.rs        # 系统 CJK 字体探测与加载
│  ├─ geo/            # 统一 2D 几何、图层/图层管理器、GeoJSON + Shapefile 导入
│  │  ├─ tri.rs       # geo Earcut 三角剖分（外环 + 孔，导入时缓存）
│  │  ├─ buffer.rs    # 缓冲区引擎（geo Buffer/BooleanOps + ArcGIS 参数语义）
│  │  └─ overlay.rs   # 叠加分析引擎（裁剪 / 相交 / 联合 / 合并 / 融合 + 属性传递）
│  ├─ map/            # 视图变换（中心 + 比例尺）、平移 / 缩放交互
│  │  └─ render.rs    # 图层渲染（Mesh 填充 + 描边 + 点圆）
│  └─ app/            # 应用层模块（mod.rs 为布局编排与工程状态机）
│     ├─ buffer_dialog.rs     # 缓冲区参数窗口（独立顶层窗口）
│     ├─ geoprocess_dialog.rs # 叠加工具参数窗口（5 个工具共用同一骨架）
│     └─ import.rs / layers_panel.rs / map_view.rs / project_op.rs / widgets.rs
└─ Cargo.toml
```

后续将按产品文档 §6.2 拆分为 workspace：`rustgis-geom` / `rustgis-spatial` /
`rustgis-data` / `rustgis-render` / `rustgis-gui`。
