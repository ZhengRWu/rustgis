# RustGIS

> 纯 Rust GIS 平台：**低内存占用 · 高性能 · 跨平台 · 内存安全**

完整产品文档见 [docs/产品文档.md](docs/产品文档.md)。

## 当前版本（v0.4.0）

- **栅格图层（v0.3 新增）**：「插入 → 添加栅格数据」打开 **TIF / GeoTIFF**，独立
  `src/raster/` 模块统一封装读取链路：
  `RasterReader → RasterDataset → RasterBand` 抽象（`RasterDataset` / `BandInfo` /
  `PixelWindow` / `RasterError` 结构化错误码：文件不存在 / 非 TIFF / 压缩不支持 /
  损坏 / 越界 / 波段非法 / 内存超限 / 已取消）。**地理参考**解析 GeoTIFF 标签
  （ModelTransformation、ModelPixelScale + ModelTiepoint、GeoKeyDirectory 的
  EPSG 代码、GeoAsciiParams 的 WKT、GCP），给出像素 ↔ 地图坐标仿射变换与
  `is_missing()` 状态；**元数据**含宽高 / 波段数 / 数据类型与位深 / NoData /
  压缩方式（无压缩、LZW、Deflate、PackBits、Fax、ZSTD、WebP）/ 分块（条带或瓦片）/
  文件大小 / BigTIFF / 内部与外部概览 / 色彩解释 / GDAL 元数据项。
  **读取不整幅加载**：按窗口只解码相交的条带 / 瓦片，解码块进 LRU 缓存（192 MiB
  上限）、单次读取受 `MAX_READ_BYTES` 限制；多波段按「平面（Planar）」或
  「交错（Chunky）」索引，支持单波段 / 任意波段组合。**金字塔**优先用 TIFF 内部
  概览，其次读外部 `.ovr`，都没有时后台构建 `<影像>.ovr`（GDAL / ArcGIS 兼容：LZW
  压缩、条带 64 行、`NewSubfileType = 1`、2×2 均值逐级降采样、最多 8 级，构建前
  弹窗询问；先写 `.ovr.tmp` 成功再改名，取消不留半截文件）。**显示采样**按地图缩放级别选层 + 最近邻重采样到
  屏幕分辨率；绘制走一条合并管线（取样 → 拉伸 → 合成一次遍历），灰度显示只读一次
  波段；块纹理按「图层 + 块坐标 + 显示设置」缓存（上限 24 块，最久未用先淘汰），
  平移时大部分块直接复用。**分块渲染（本次新增）**：借鉴 QGIS 的
  `QgsRasterIterator` / `QgsRasterDrawer`——不再整窗一张纹理，而是按屏幕像素固定
  边长 512 的**块**（`TileKey{level,col,row}`）逐块解码、逐块贴图，横纵共用同一个
  源像素步长，块在屏幕上恒为正方形；块按「到视口中心距离」排序派活、最多 3 个并发，
  新旧网格共存（旧块没被缩到 2 倍以上就继续画），完成一块就重画一块。
  这样既没有纹理上限带来的挤压（圆变椭圆），也不会因为一块解码失败或缩放越级
  整屏退回底图；换量程 / 换 Gamma 只换 uniform，不重新解码。
  **大影像异步渲染（v0.4 新增）**：超过 400 万像素的图层
  不在界面线程解码——全幅先出一张长边 768 的**底图**兜底，细节块在后台线程按
  当前视口解码后逐块无缝替换（**最多 4 块并行**，每块线程自带一份数据集，
  4 块 ×512² 实测 1.46 s → 0.83 s）；缩放级别按非对称容差复用（放大 1.25 倍内、
  缩小 1.75 倍内继续用旧块），一次滚轮不再触发重建，不会「一放大就整幅变糊」；
  解码线程通过快照（`DatasetSnapshot`）取值，绘制线程全程只 `try_lock`、永不等锁，
  后台统计与解码都不会卡住画面。**CPU 合成（与 QGIS 一致）**：波段 → RGB、拉伸 /
  反向 / 每通道 Gamma / NoData → 背景或透明都在 CPU 上按块合成（
  `QgsMultiBandColorRenderer::block()` 的同一套语义），放大交给纹理过滤（2 倍以内
  双线性、超过 2 倍按 QGIS `maxOversampling` 切最近邻，深度放大是清晰像素块而不是
  一片糊影），不再依赖 GL 上下文与浮点纹理过滤，也不再有只在截图里才能验的脏路径
  （历史显卡方案见 `docs/产品文档.md` §12.7）。**图层接入**：图层面板显示三色栅格图例、
  参与叠放 / 显隐 / 删除、自动参与「缩放至全图」；**双击图层打开「图层属性」**
  弹窗为**独立系统窗口**（`show_viewport_immediate`，原生标题栏与最小化/最大化/关闭，
   内部按 Win32 观感自绘页签、分组框、列表框与按钮）
  （对标 ArcGIS）：常规 / 源 /
  范围 / 显示 / 符号系统 / 时间 六个页签，符号系统支持**拉伸**（单波段灰度）与
  **RGB 合成**（红 / 绿 / 蓝 / Alpha 波段下拉）、显示背景值、NoData 透明、拉伸
  类型（百分比截断默认 0.5 / 最小值-最大值 / 标准差 / 无）、最小最大值、反向、
  每通道 Gamma（默认 1.0）、统计数据展示与「计算统计」按钮；统计优先读文件内
  GDAL 统计值，否则后台扫描像素（超过 1600 万像素时抽样估算并标注）。导入、
  统计、金字塔构建全部在**后台线程**执行，主线程只做非阻塞轮询。
- **Sentinel-2 SAFE 产品包（v0.4 新增）**：「插入 → 添加 Sentinel-2 SAFE 产品包...」
  选择解压后的 `.SAFE` 目录（也接受 `MTD_MSIL*.xml` 文件本身）即可直接浏览。包级
  解析走 `src/raster/safe.rs`：识别 L1C / L2A 产品级别（目录名或 `PRODUCT_TYPE`），
  读 `GRANULE/<…>/MTD_TL.xml` 的 `Tile_Geocoding`（ULX / ULY / XDIM / YDIM +
  `HORIZONTAL_CS_CODE` → EPSG），枚举 `IMG_DATA/R10m|R20m|R60m` 下的波段文件并按
  TCI → B04 → B03 → B02 → B08 → 红边 / 短波红外 → 气溶胶 / 水汽 / 场景分类 /
  掩膜 的顺序排列，波段名带中文说明（`B04 红`、`B8A 窄近红外`、`TCI 真彩色`…）。
  同一波段在三个分辨率目录里各有一份副本，**只保留最精细的那一份**
  （真实 L2A 产品的 42 个 `.jp2` → 18 个波段）。
  **像素解码**委托纯 Rust 的 `j2k`（JPEG 2000）：`src/raster/jp2.rs` 缓存码流
  （LRU 6 个文件）、按「源区域 + 1/2·1/4·1/8 降采样」解码，只取视窗像素；大区域
 全分辨率解码按 64 MiB 条带切分（`j2k` 的分量常驻上限是 512 MB，真实 L2A 的 10 m
  三分量波段整幅约 540 MB）；多分辨率网格按波段自身分辨率换算（10 / 20 / 60 m →
  相对因子 1 / 2 / 6），再把 20 m、60 m 波段最近邻重采样到显示窗口。统计同样改为
  整幅降采样（长边 2048、标记「估算」），避免逐窗全分辨率解码撞上内存上限。
  SAFE 的多分辨率网格本身就是概览，**不需要也不提示
  构建金字塔**（虚拟层级铺到 1/32，全幅缩略直接取深层窗口，解码像素少一个数量级）；
  显示、符号系统、统计、图层属性、工程持久化与 GeoTIFF 完全一致
  （同一套 `RasterDataset` / `RasterLayer` 接口）。
- **缓冲区分析（v0.2.2 新增）**：「地理处理 → 缓冲区...」打开**独立顶层窗口**
  （egui 多视口 → 真正的系统窗口，可与主窗口并列摆放），参数对标 ArcGIS「缓冲区」
  工具：输入要素 / 输出要素类（GeoJSON）、距离 [值或字段]（米·千米·英尺·英里·码·
  海里·度）、侧类型 FULL / LEFT / RIGHT / OUTSIDE_ONLY、末端类型 ROUND / FLAT /
  SQUARE、融合类型 NONE / ALL / LIST（按字段取值组合融合）；右侧上下文帮助随悬停
  参数切换；确定后在后台线程计算并**自动把结果图层加入地图**（仅当结果超出当前
  视图时才自动缩放）。几何运算全部委托 **`geo` 0.33**（Buffer / BooleanOps /
  Earcut，纯 Rust、无 C 依赖）；属性来自 GeoJSON `properties` 或 Shapefile `.dbf`。
- **地理处理：叠加分析（v0.2.2 新增）**：「地理处理」菜单下另有对标 ArcGIS
  「Overlay」工具箱的 5 个工具，与缓冲区共用同一套独立窗口骨架：
  **裁剪**（用面图层切分输入：面取交集、线被切断、点保留面内）、**相交**（所有输入
  的公共部分，属性按各输入字段并集合并、重名加 `_1`/`_2` 后缀）、
  **联合**（多个面图层的并集切成互不重叠的要素，重叠区按输入顺序先到先得、
  面积不重复计入）、**合并**（纯拼接，不做几何运算）、**融合**（按字段取值分组
  归并，不勾选字段即「融合全部」）。输入列表的**勾选顺序即叠加顺序**（第 1 个是
  主输入，决定字段列表与默认输出名）；结果同样在后台线程计算、写出 GeoJSON
  （按要素带 `properties`）并自动加入地图；每个工具一种强调色。
- **工程文件（.rustgis）**：「文件 → 新建工程 / 打开工程... / 保存 / 另存为...」
  对标 ArcGIS 文件菜单：单文件 JSON（带版本，当前 v4）保存全部图层（含属性表）+
  地图视图；**打开/保存全程后台线程**（文件对话框 → 序列化/解析 + 三角剖分），
  窗口持续响应；有未保存更改时「新建 / 打开 / 退出（菜单或标题栏 X）」先弹
  "保存更改？"三按钮提示（保存 / 不保存 / 取消）；标题栏显示「工程名 — RustGIS
  版本」（未保存为"未命名"）；
- **数据导入**：「图层 → 添加图层」/「数据 → 导入数据」→ 系统文件选择器，
  支持 **GeoJSON**（`.geojson` / `.json`）与 **Shapefile**（`.shp`，DBF 编码自动检测，含 GBK）；
  **导入全程在后台线程执行**（文件对话框 → 解析 → 几何展开 → 三角剖分），
  期间窗口持续响应并显示阶段提示，导入成功自动缩放至全图并在状态栏提示要素数，
  失败弹出错误对话框；
- **地图渲染**：点 / 线 / 多边形（导入时 Earcut 三角剖分，运行时三角网格批绘制）；
  多边形孔参与填充（孔感知剖分）；
- **视图交互**：左键拖动平移、滚轮以光标为中心缩放、双击缩放至全图；
  「视图 → 放大 / 缩小 / 平移 / 缩放至全图」菜单可用；
- **图层管理面板**（左侧）：图例符号 + 图层名（面/线/点不同符号，配色随样式）、
  隐藏图层弱色、拖拽行调整叠放顺序（拖动中显示落点指示、松手生效）、
  右键菜单显示/隐藏 / 删除（红色警示）；
- **整应用白底浅色主题**：窗口 / 面板 / 地图画布 / 工具对话框全白，1px 发丝线分隔，
  交互态与强调色统一走 ArcGIS 蓝（`#0071BC`）；Windows 下无控制台窗口，启动即显示主窗体；
- **提示类弹框走系统原生样式**：「功能开发中」/ 错误 / 关于 / 「是否构建金字塔」/
  「保存更改？」全部用**系统原生对话框**（Windows TaskDialog、macOS NSAlert、Linux GTK），
  图标、字体、按钮文案与操作系统一致，不再自绘；对话框在后台线程弹出、UI 循环非阻塞
  轮询结果，弹框开着时地图照常平移缩放；
- **GUI 骨架**（v0.1）：`eframe / egui`（默认 1280×800）、9 个完整菜单、
  未实现功能统一弹出 **"正在开发中"** 原生对话框、「退出」关闭窗口、
  「关于 RustGIS」显示版本与渲染字体、状态栏（状态 | 光标经纬度 | 版本信息）；
- **多语言（i18n）**：简体中文 / English / 日本語，启动时跟随系统区域设置，
  可在「帮助 → 语言」中切换；
- **CJK 字体自动加载**：启动时按平台加载系统中文字体（微软雅黑 / 苹方 /
  Noto CJK 等），保证中文与日文正常显示。

## 运行

```bash
cargo run --release     # Windows 下也可直接双击 run.bat
```

地图渲染是逐顶点紧循环（每帧把几十万顶点投影到屏幕并写进顶点缓冲），
**请用 release 运行**：dev profile 即使开了 `opt-level = 1`（见 `Cargo.toml`）
在小数据量下够用，但大图层仍会掉帧。

发布构建：

```bash
cargo build --release
```

测试与质量门：

```bash
cargo test --bin rustgis   # 几何（Earcut 剖分/缓冲区/布尔融合/叠加分析）/ 视图变换 /
                           # 导入展开 / 端到端导入导出 / 工程文件往返 / i18n 覆盖 /
                           # 栅格（真实 TIF 夹具：普通/带 CRS/多波段/压缩/大尺寸/无地理参考）/
                           # Sentinel-2 SAFE（包解析单元测试 + 真实 JPEG 2000 端到端）/
                           # 独立窗口对话框（缓冲区 + 叠加工具 + 栅格图层属性）
cargo clippy --all-targets   # 零警告为门禁
```

│  │  ├─ stats.rs     # 统计累加器（min/max/mean/std + 4096 桶直方图 + 分位）
